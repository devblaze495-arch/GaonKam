# User flow

## User journey overview

1. A user registers and completes a basic profile.
2. The user can create a work requirement or a service listing.
3. Other users browse locally relevant jobs or services.
4. A user can apply, accept, or hire based on the requirement.
5. The job enters active execution once workers are selected.
6. Completion is confirmed after work is finished.
7. Both parties can rate each other.
8. Trust and reputation are updated according to job outcomes.

## Core interaction flow

```text
User creates job
  -> Job visible to others
  -> Applications flow in
  -> Poster reviews applicants
  -> Poster selects workers
  -> Work begins
  -> Completion is confirmed
  -> Ratings are posted
  -> Trust score updates
```

## Future admin involvement

- Review disputes
- Moderate ratings or reviews
- Investigate suspicious activity
- Suspend or restore accounts
- Manage service categories and reported issues
